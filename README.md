# 心周期と心音

大学1年生向け、約30分の講義用教材。心臓の解剖、肺循環・体循環、心周期の6期、圧・容積・心電図・心音の対応を扱う。

公開URL：https://ashukuri.github.io/cardiac-cycle-lecture/

`index.html` をブラウザで開く。画像はHTML内に埋め込まれており、ダウンロードしてオフラインでも利用できる。投影時は全画面表示を推奨。

波形・心臓の変形・合成音は教育用の模式表現で、実測値・診断用シミュレーションではない。

素材の出典・ライセンス・改変内容は [ATTRIBUTION.md](ATTRIBUTION.md) と教材の「出典」に記載。
